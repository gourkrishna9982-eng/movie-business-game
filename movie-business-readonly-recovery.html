Movie Business 3 — Read-only Recovery

This separate helper only reads the game's hidden Google Drive app-data save and lets you download a backup. It does not start the game, alter local storage, create saves, or send any write/update/delete requests to Drive.

Before you begin

Use the same Google account that held your old studio. This helper is intended to be uploaded into the movie-business-game GitHub Pages repository so it runs on the same website origin as the game.

Do not use NEW STUDIO, SAVE TO DRIVE, or CONTINUE in the main game until you have checked and downloaded the save here.

Safety notes

Google's appDataFolder is hidden from the normal Drive website. A missing save may mean the file is absent, the wrong Google account/app authorization was used, or access failed; it does not by itself prove that every older copy is gone.

Drive may not retain downloadable older revisions unless they were marked “Keep forever”. This helper lists revision metadata, but never changes revision settings.
